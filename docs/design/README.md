# Design notes

The current UI is a port of zeron's settings surface onto zeron's GPUI stack.
The authoritative descriptions are:

- product/architecture: `docs/PROJECT.md`
- module map and adaptation rules: `docs/memory/zeron-stack-port.md`
- port plan (phases, decisions, gates): `docs/plans/completed/zeron-stack-port.md`
- upstream provenance and licensing: `THIRD_PARTY_NOTICES.md`

`archive/` holds the design specs of the dropped pre-port approach (gpui-kit
plus a patched `gpui-component`); they are kept as history and are not
authoritative.
